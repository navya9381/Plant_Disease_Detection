# 🌿 AgriVision AI — Plant Leaf Disease Detector

**AgriVision AI** is a lightweight, responsive web interface designed to simulate real-time AI-based plant leaf disease detection. It helps farmers, horticulturists, and plant enthusiasts identify crop diseases from leaf imagery and provides immediate treatment plans and risk advisories.

---

## ✨ Features

- 📸 **Image Upload & Drag-and-Drop:** Easily upload custom leaf images for analysis.
- 🔬 **Interactive AI Scanning Simulation:** Visual laser-scan effect during disease pathology processing.
- 🩺 **Comprehensive Disease Diagnostics:** Displays disease status, classification type, and model confidence score.
- ⚠️ **Risk & Caution Advisories:** Outlines contagiousness, transmission risks, and crop impact.
- 💊 **Actionable Cures & Treatment:** Clear, step-by-step guidance on fungicides, pruning, and prevention.
- 🖼️ **Preset Demo Samples:** Built-in test samples (Late Blight, Apple Scab, Corn Rust, Healthy) for quick testing.
- 🎨 **Modern Green UI/UX:** Clean, white/green theme tailored for agricultural tech apps.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla ES6+)
- **Icons:** FontAwesome 6
- **Styling:** Custom CSS variables, CSS Grid, Flexbox (No external frameworks required)
